# Karui web client

The browser app of [Karui](https://karui.eu), a private AI chat. The whole privacy
promise is kept here, in the browser: chats and projects are encrypted before they
leave the device, the server stores only ciphertext, and requests to the model go
encrypted straight to an attested enclave.
